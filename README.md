# Magic Poker Lite

手機直版、第一人稱視角的 1v1 簡化德州 Demo，玩家對戰固定的手繪卡通怪獸 NPC。兩張底牌、五張公共牌、四街下注，候選行動按鈕顯示 NPC 的真實 FOLD／RAISE 回應機率，中央抽選顯示所有正機率回應。遊戲使用英文；機率工具與專案文件使用繁體中文。

目前 **v32 牌桌視覺流程調整，本地完整流程驗證通過**：POT 金額與後方籌碼居中，對手資產移到右上，隱藏牌堆；常駐底板只顯示當前行動，完整決策機率放在 POT 下方，公共牌上移、玩家手牌及牌型下移。按鈕改為有厚度的圓角造型與清楚的對手機率區，翻牌／轉牌／河牌採較連續的翻面。沿用 v31 繁體中文機率工具、v30 預設資產 10,000 與 TOTAL WIN 金幣演出。玩家控制仍固定 FOLD／CALL／RAISE，付費動作顯示本次花費，FOLD 與免費 CALL 只顯示名稱。規則沿用 v26 小盲半 BET／大盲一 BET，不改機率公式、RNG、結算、JP 或工具匯出格式。這是一款使用虛擬籌碼的本機遊戲原型，未接帳號、支付或後端持久錢包。最新驗證與發布狀態見 [手機與部署紀錄](docs/06-mobile-and-deployment.md)。

## 目前功能

- **入場引導**：Beat the boss／Choose your move／Jackpot bonus 三頁圖解，清楚示範 2＋5 張牌選最佳 5 張、動作用途、完整機率範例及 JP，不再放微型遊戲截圖。入口收起後方牌桌資訊，只保留角色場景、JP 與唯一原資產列，關閉還原。MINIMUM、BET 1／＋／－與獨立 FIGHT 保留；選值不扣款、不抽 RNG，FIGHT 才建立牌桌並抽盲，正常下一手不重彈。
- **大小盲投入**：BET 代表大盲與最低入場資產的縮放基準，小盲固定為半 BET。首次以 50/50 抽盲位，之後逐手輪替；每手 SB／BB 各自動投入一次，舊 `smallBlind:0` 設定會轉為大盲的一半。小盲／莊位翻牌前先行動，大盲翻牌後先行動。
- **四街與合法行動**：過牌、下注、跟注、棄牌與固定尺度加注，每街最多一次加注。介面固定 FOLD／CALL／RAISE；中央 CALL 可代表免費過牌或付費跟注，右側 RAISE 可代表開注或加注，不改底層真實動作。付費時顯示籌碼與本次新增花費，免費 CALL 與 FOLD 只顯示名稱。
- **真實機率與可調起手**：按鈕只列同街有效回應的 NPC FOLD／RAISE 原機率；中央真比例長條顯示全部正機率實際動作，含 CALL／CHECK／BET，marker 對應真實 `selected.roll`。NPC 先手或換街無有效按鈕來源時直接呈現當下分布，不借用舊來源。機率不重新正規化，只抽一次；預覽與動畫不改 RNG 或帳務。雙方起手重抽可獨立設定，只評估兩張起手牌，不依最終輸贏挑牌。
- **常駐當前行動**：POT 下方底板只顯示目前發牌、玩家或 BOSS 行動；籌碼移動不另列 POT 階段，結束為 HAND COMPLETE。相同內容不重複播報，完整訊息保留於提示與無障礙狀態。中央決策與 TOTAL WIN 共用這一區域，與上方的公共牌、精確 POT 及來源籌碼分開。
- **最佳五張與攤牌**：玩家可見牌不足五張時全部亮金框，之後亮出包含 kicker 的最佳五張；NPC 逐張揭牌，在原底牌與公共牌亮紅框，共用牌內金外紅。公開第一張後僅以公開資料枚舉 44 張可能第二底牌；第二張公開後顯示精確勝負，不偷讀暗牌。
- **持牌怪獸與帳務演出**：角色表情只在結果可公開後切換。v29 單顆桌上 coin 抽盲後飛至座位，SB／BB 依序入 POT；投入、退款、派彩仍分開。結算改用桌上 TOTAL WIN 顯示玩家底池返還＋JP，排除退款，不自動開結算 modal；手動明細保留 TOTAL RETURN／NET RESULT。餘額跨手及離桌保留，動畫不重複扣款或入帳。
- **機率工具**：共用遊戲引擎，支援分組參數、雙方重抽／指定牌、策略比較、Worker 跑批與停止、95% 信賴區間、底池／JP 分層統計、保存及 JSON／CSV 匯出。模擬每手重置等額帶入，與遊戲跨手保留餘額分開計算。

本作使用 52 張牌，沒有鬼牌、SCATTER 或免費遊戲。原 Boss Duel、Hands Up、Final Table 資料夾保持唯讀；執行本作不依賴舊目錄，所用素材副本與來源見 [素材紀錄](assets/README.md)。

## Jackpot 與 96% 的範圍

JP 預設啟用：皇家同花順 **200×BET**、同花順 **50×BET**、四條 **20×BET**。玩家正常攤牌時只領最高一獎，可使用零／一／兩張底牌，不必贏得底池；棄牌不領，NPC 不領。JP 與底池派彩、未跟注退款分開記帳。

**0.96 是已匹配底池的返還係數，不是任意策略或含 JP 總 RTP 的保證。** 原型將匹配底池扣除 4% 結算費，未跟注籌碼全額退回、不納入有效投入與 RTP。對稱條件下的底池回收期望與含 JP 的總回收必須分開；策略與起手設定會影響實測，不暗改牌局以湊目標。這項結算費是原型模型取捨，尚非已確認的商業收費方案。

既有 260,000 手數學資料屬 **SB 5／BB 10、未含 JP 的歷史基準**；即使 v26 盲額相同，也不代表本輪重跑或含 JP 模型已校準。v14 單大盲輸出同樣保留原版本。舊版積極策略的底池實測曾高於 100%；目前仍需評估策略與 JP 的整體分布，不能視為商用封版數學。
