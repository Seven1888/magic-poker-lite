# Magic Poker Lite

手機直版、第一人稱視角的 1v1 簡化德州 Demo，玩家對戰固定的手繪卡通怪獸 NPC。兩張底牌、五張公共牌、四街下注，在候選行動按鈕內顯示 NPC 的真實 FOLD／RAISE 回應機率。遊戲與機率工具使用英文，專案文件使用繁體中文。

目前入口為 **v25 實際遊戲畫面教學與 BET 設定**，牌桌為 **v25 紅色桌布、霧面籌碼、右上牌庫、分組公共牌與精簡動作按鈕**。這是一款使用虛擬籌碼的本機遊戲原型，未接帳號、支付或後端持久錢包。

## 本機啟動

需要 **Node.js 20+**，不需 `npm install`。在此資料夾執行：

```sh
npm start
```

也可執行 `node server.cjs`，或在 Windows 雙擊 `啟動遊戲.cmd`。

- [遊戲](http://127.0.0.1:4177/)

## 目前功能

- **同窗入場引導**：載入頁面自動開啟 See the odds／Make your best 5／Jackpot bonus 三頁圖解；每頁保留 BET 加減、六個預設、餘額、最低資產與 PLAY。示例標明 `EXAMPLE ODDS`，JP 金額隨 BET 更新，停用時顯示 OFF。調整 BET 不扣款、不抽 RNG；按 PLAY 才建立牌桌並抽盲，正常下一手不重彈。
- **單一大盲投入**：BET 代表大盲與最低入場資產的縮放基準。首次以 50/50 抽盲位，之後逐手輪替；每手只有 BB 自動投入 BET，SB 起手投入 0、保留翻牌前先手身份。這不是標準雙盲規則。
- **四街與合法行動**：過牌、下注、跟注、棄牌與固定尺度加注，每街最多一次加注。`CHECK 0` 只表示當次零成本；先手過牌仍可能遇到 NPC 當街下注，後手過牌可能結束當街。
- **真實機率與可調起手**：同街有效候選行動的 NPC FOLD／RAISE 原機率直接顯示在玩家按鈕內；其他回應省略，不重新正規化。分布鎖定後只抽一次；預覽與動畫不改 RNG 或帳務。雙方起手重抽可獨立設定，只評估兩張起手牌，不依最終輸贏挑牌。
- **最佳五張與攤牌**：玩家可見牌不足五張時全部亮金框，之後亮出包含 kicker 的最佳五張；NPC 逐張揭牌，在原底牌與公共牌亮紅框，共用牌內金外紅。公開第一張後僅以公開資料枚舉 44 張可能第二底牌；第二張公開後顯示精確勝負，不偷讀暗牌。
- **持牌怪獸與帳務演出**：中性、微笑、嘴角下垂三種場景在結果可公開後切換表情。中央 POT 搭配五堆示意籌碼，投入、未跟注退款與派彩分開演出；結算分列 `TOTAL RETURN` 與 `NET RESULT`，保留帳務明細。餘額跨手及離桌保留；動畫不重複扣款或入帳。
- **機率工具**：共用遊戲引擎，支援分組參數、雙方重抽／指定牌、策略比較、Worker 跑批與停止、95% 信賴區間、底池／JP 分層統計、保存及 JSON／CSV 匯出。模擬每手重置等額帶入，與遊戲跨手保留餘額分開計算。

本作使用 52 張牌，沒有鬼牌、SCATTER 或免費遊戲。原 Boss Duel、Hands Up、Final Table 資料夾保持唯讀；執行本作不依賴舊目錄，所用素材副本與來源見 [素材紀錄](assets/README.md)。

## Jackpot 與 96% 的範圍

JP 預設啟用：皇家同花順 **200×BET**、同花順 **50×BET**、四條 **20×BET**。玩家正常攤牌時只領最高一獎，可使用零／一／兩張底牌，不必贏得底池；棄牌不領，NPC 不領。JP 與底池派彩、未跟注退款分開記帳。

**0.96 是已匹配底池的返還係數，不是任意策略或含 JP 總 RTP 的保證。** 原型將匹配底池扣除 4% 結算費，未跟注籌碼全額退回、不納入有效投入與 RTP。對稱條件下的底池回收期望與含 JP 的總回收必須分開；策略與起手設定會影響實測，不暗改牌局以湊目標。這項結算費是原型模型取捨，尚非已確認的商業收費方案。

既有 260,000 手數學資料屬 **SB 5／BB 10、未含 JP 的歷史基準**，不代表目前單大盲與 JP 模型已校準。舊版積極策略的底池實測曾高於 100%；目前仍需評估策略與 JP 的整體分布，不能視為商用封版數學。
