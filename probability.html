CONTROLS

Settings

01 Simulation

Each hand starts with the same stack and alternates the big blind. Only the big blind posts automatically; the other seat starts with no bet. Groups set sample size; they are not continuous bankrolls. Progress updates every 250 hands.

02 Base return & buy-in

The 0.96 factor applies only to the matched pot after fees. Player base RTP depends on strategy and dealing. Total RTP including JP is measured separately.

03 Blinds & street bets

One raise per street. Bets and raises use fixed increments, capped by effective stacks. Game adds 500 ms; reduced motion skips it. Animation does not affect sampling.

05 Opponent starting hand
06 Opponent action model
07 Jackpot prizes

At showdown, the player’s best five cards earn only the highest qualifying prize. Zero, one or two hole cards may be used. Winning the pot is not required. Folds do not trigger JP. Prizes multiply the big blind, with no extra wager or pot fee.

Settings → shared game engine → worker batches → statistics / export. This lab uses the same rules as the game.
