# Magic Poker Lite 現行設計

先讀 [工作規範](../../../AGENTS.md)。最新使用者要求優先。2026-10-07 使用者選擇方案 B，保留 99%／雙池／JP 並允許 NPC 切換暗牌；已要求完成後提交、推送 Git 並建立新聊天室。沿用目前 checkout；同層原三款永久唯讀。

閱讀 [v53 完整規格](../../../docs/16-v53-holdem-spec.md)、[規則與數學](../../../docs/04-game-flow-and-math.md) 及 [API](../../../API-CONTRACT.md)。[驗證紀錄](../../../docs/06-mobile-and-deployment.md) 只寫實際檢查；發布前不得沿用舊候選測試或舊 Actions 宣稱本輪成功。

正式 `pooled-holdem` 在開手隔離預建玩家牌、公牌序和必要 NPC win／nonWin 配對，原子發布；正式付費才用原計分公式抽結果並選既存配對。保存精簡的所選路徑，不預先實體展開完整 NL 樹。保留 .99 唯一計分、全額匹配 POT、全額退款、80/20 個人雙池、CD 及有資格 JP。桶與 JP 用 BB 單位；未派池餘額不是玩家資產或實測 RTP。

入口選 SB，BB=2SB、買入100SB；錢包與桌籌碼分離，同桌不補碼，NPC 每手匹配玩家當時碼。首手抽盲、後續輪替；五個虛線空框與逐街3/1/1；真實 CHECK/CALL、BET/RAISE、多次合法再加注。兩型對手每街先鎖強弱，同街換暗牌仍不改機率；各回合重新抽行為，進攻再抽50/35/15尺寸。合法動作提交完整物件或ID，不能只用type覆蓋尺寸。

公開三情境機率只含數字，參考勝率只讀玩家及已揭牌，不能洩漏 NPC 實際暗牌、原因或未來公牌。UI 動畫、預覽及音效不增加 RNG 或帳務交易。保存未完手、結果控制狀態、街道快照、RNG、錢包、雙池及對手序列；重整不回退買入，不重抽。

機率工具共用正式引擎。一般外部錢包無限但桌碼有限100SB，歸零才模擬新入桌；退幣使用錢包加桌碼的總資產。空白種子一次隨機、0有效；一次開始一般加退幣，中止不發布部分退幣比例。報表明示實際模式與實測RTP，不宣稱完整行動樹已列舉。

修改數學後核對合法下注、短全下、實際結算、池／JP 對帳、同街鎖定與未完手恢復；跑必要測試及共用 Worker。以桌面 Chrome 驗證1440／375／320px設定和結果，不把viewport說成實體手機或長期RTP認證。發布與新聊天室連結由實際完成結果填入。
