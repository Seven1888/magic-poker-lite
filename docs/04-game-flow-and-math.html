Magic Poker Lite 規則與公式

v54／2026-10-07：已通過驗證並推送 Git／部署 Pages。正式模型pooled-holdem及v53數學／機率規格不改；本輪調整買入、操作資訊、美術、收款及重整入口。呈現需求見 v54規格，遊戲與數學見 v53規格，驗證與發布證據見 驗證紀錄。

1. 正式模型與一手流程

遊戲採單挑德州下注流程，加上結果計分和個人雙池。開手布局固定玩家底牌、公牌順序，並預建所需NPC贏／不贏配對；玩家實付時按公式決定是否選另一配對。這不是雙方底牌永久固定、全牌均勻隨機的自然德州。

  1. 入口依序顯示可調SB、連動BB、連動BUY-IN；按FIGHT從錢包買入100SB，先完成雙方至少1秒的無手牌買入表演。
  2. 首手50/50抽盲位；後手交換SB/BB。各下盲注、發兩張底牌。
  3. Preflop公共牌顯示五個虛線空框，SB先行；SB補平後BB仍有CHECK/RAISE選擇。
  4. Flop發3張、Turn1張、River1張，這三街BB先行。
  5. 每街先鎖對手強弱及行為機率，雙方按合法動作下注，可反覆再加注。
  6. 一方FOLD立刻結算；雙方已無下注可做則補牌攤牌，畫面仍按3/1/1演出。
  7. 下一手保留玩家桌碼，NPC新起始碼匹配玩家；結算後可離桌兌回餘碼。玩家歸零則先完成結果表演，再自動離桌回SB／FIGHT入口。

無未選動作入帳，動畫與預覽不增加抽籤或交易。本次沒有新增燒牌動畫。

2. 小盲、大盲、買入與錢包

項目定義
SB入口選到的金額
BB2 × SB
買入100 × SB = 50 × BB
BALANCE桌外錢包
CHIPS本桌可下注的實際籌碼

選SB10：BB20、買入1000。BALANCE10000入場後為9000、CHIPS1000；若玩家SB，扣盲後玩家990、NPC980、POT30。買入金額先從BALANCE扣一次，錢飛至CHIPS後才演出下盲。選單變動本身不扣款。

入口由左到右SB／BB／BUY-IN，只有SB可調，另外兩者按2SB／100SB連動。買入表演預設1400ms，最低1000ms，不除以遊戲速度；雙方沒有手牌或背牌，籌碼飛至各自區域後逐步形成實體堆，金額由0同步累加至買入額，完成後才下盲發牌。畫面移除籌碼上方CHIPS字樣，保留籌碼堆與金額。動畫不再扣款或增加資產。

桌碼跨手累積，同桌不能局中或手間補碼；下注只扣CHIPS。每手扣盲前NPC碼匹配玩家當時碼。玩家有正數碼即可續手，不足完整盲注就下剩碼；零碼停止。盲注同桌固定，結算後離桌一次兌回剩碼，再入場才是新買入。買入、離桌、NPC起始配置都不是下注或RTP返還。

3. CHECK、CALL、BET、RAISE

沒有待補差額顯示CHECK，有差額顯示CALL。本街尚未下注顯示BET，已有下注或盲注顯示RAISE。點進攻按鈕向上展開連接選單，再選本次實付金額才提交。

三個按鈕保持66px高度，使用FOLD／CHECK／CALL／BET／RAISE五狀態透明美術；右側文字為BET ▲或RAISE ▲，移除AMOUNT。CHECK／CALL下方FREE或金額、各加注尺寸金額前加籌碼圖示。取消NPC手牌下的行為機率橫條，改將回應資訊放在玩家按鈕上方，資訊區向上騰出空間。

尺寸選單由上到下ALL IN／1× POT／0.5× POT，同額依引擎合併、不重複。每個尺寸左側預覽該精確合法動作的NPC回應，預覽不推進正式RNG、不改牌或池。CHECK／CALL若結束本街，顯示NEXT STREET而不洩漏新街機率；已結算顯示SHOWDOWN。

尺寸NPC條件機率玩家
半池50%自由選
全池35%自由選
ALL IN15%自由選

P是目前POT，C是尚需CALL差額，s是自己本街已付，x為0.5或1：

本次實付 amount = C + x × (P + C)
本街總額 to = s + amount
ALL IN amount = 自己剩餘 CHIPS

原底池100，對方下注50之後P=150、C=50；半池本次付150，全池付250。UI顯示本次付多少，不是本街總額。

最小開注BB；最小完整加注增量為前次完整BET/RAISE增量，每街初始基準BB。半池／全池先提高至最小合法額，再以自己的全部碼封頂。同額合併一項並加總尺寸權重；抽半池／全池也可能因碼不足成為ALL IN，因此實際全下不一定只有15%。

CALL不足用剩碼；短ALL IN不重開已行動者的加注權。對方已全下不再提供RAISE。雙方可多次合法再加注，無每街一次上限。HU未匹配投入結算全退，不建立第三人的邊池。

4. 兩型對手與每街鎖定

ID工具名稱遊戲名稱
maniac激進AGGRESSIVE
caller不激進PASSIVE

首型各50%，其後交替且不連續重複，跨離桌與重整保存上一型。研究可明確固定一型。舊sniper/trapper設定遷caller。

每街開始，在任何一方該街行動前，只用NPC自己的牌、已揭公牌與已完成街道歷史，判定一次「強／不強」。同街玩家下注額、再加注次數及NPC換配對都不改此分類；下一街才依當時NPC配對重算。每次NPC行動仍重新抽行為。

5. 強／不強明確條件

符合任一條為強，否則不強。

階段強的判定
Preflop底牌對子，或兩張點數都至少10，或同花且含A
所有Postflop目前最佳五張對子以上，公共牌本身的對子也算
Flop／Turn全部可見牌剛好四張同花；或有兩端均可補成順子的四連點
Flop／Turn卡順詐唬缺內部一點成順；至少一個構成點數只能由底牌提供；至少一張底牌大於公牌最高點
River未中聽牌詐唬目前高牌；Turn NPC曾BET/RAISE；Turn涉及底牌的四花或雙頭順，到River沒補成
River阻擋牌詐唬目前高牌；Turn NPC曾BET/RAISE；公牌恰三張同花，NPC持該花A

A只在順子最低或最高，不繞接。2345/TJQK為雙頭順，A234/JQKA不是。涉及底牌的雙頭順至少一個必要點數只由底牌提供；四花至少一張該花在底牌。公共牌本身四花／雙頭順在Flop/Turn也算強，但River未中聽牌條件仍需底牌參與與Turn進攻。

River讀Turn開始保存的聽牌證據；之後換NPC配對不能改寫Turn快照。這些是程式可判定的遊戲條件，不代表真人撲克策略的統計平均。強包括成牌、聽牌及指定詐唬，不添加最大牌不棄牌等隱藏例外。

7. 原子布局與精簡結果路徑

正式pooled-holdem使用精簡控制器，不在開局展開全部無限加注分支樹。開手先抽root與特殊資格，再預建本手玩家牌、公牌序及必要NPC配對：root win只需win，root nonWin需win/nonWin兩組。

布局重試保留原target與資格；超限失敗不提交正式盲注、手序、水池或RNG。布局成功才發布。玩家底牌／公牌固定，NPC可切換已建合法配對；nonWin可能輸或平手。

玩家實付操作在隔離副本按原結果公式抽票、安裝對應NPC配對，再執行下注／換街，成功才一次發布。非玩家實付、免費行為或原win繼承不重抽付費結果。未選動作不消耗正式結果票、不動池。預覽只用clone。

同街配對切換保留已公布概率；跨街時先安裝目前配對，才判新街。所選路徑、布局、資格、RNG與街道快照均可序列化，以便載入時還原舊桌帳務並完成結算。

8. .99計分、付費池與CD

α=conversionRate，預設0.99，是唯一結果計分係數。正式匹配POT全額派彩，targetRtp=1，不另扣4%或第二筆折扣。α設定不等於實測RTP。

root的m0為雙方實際盲注較小者：

rootScore = round6(m0 × α)
rootDenominator = round6(2 × m0)
rootProbability = clamp(rootScore / rootDenominator, 0, 1)

正常α=.99時root win率49.5%。root不新增雙池、不使用付費池。

前target為nonWin且玩家本次實付c，C為玩家之前總投入，S為NPC本手起始碼，B為當前本桶付費池：

M = min(C + c, S)
D = round6(2 × M)
score = round6(c × α)
U = CD == 0 ? min(B, round6(max(0, D - score))) : 0
p = clamp(round6(score + U) / D, 0, 1)

U最多把機率補到100%，實際選中的這次付費才使用U；未選操作不扣池。原target為win則非棄牌繼承，不重新抽結果、不用付費池、不減CD。免費動作不抽付費結果。

結果票以百萬刻度量化：winningNumbers=round(p×1000000)，roll=1+floor(rng×1000000)，roll≤winningNumbers即win；0%/100%仍消耗其正式結果票。CD預設0..0；前nonWin且實付才依規則減少，使用池後抽包含端點的新CD。固定CD上下限相同不需額外抽CD票。

9. 贏節點分池、桶與JP

贏節點玩家實付保存累計投入區間[from,to]。整手最後m=min(雙方投入)，只有有效匹配部分入池：

effectivePaid = max(0, min(to, m) - from)
credit = round6(effectivePaid × α)
paidActionAdded = round6(credit × 0.8)
specialAdded = round6(credit - paidActionAdded)

盲注、買入、未匹配退款與未選動作不入池。即使後來棄牌，先前真實贏節點的有效付款仍依原區間規則對帳，不把全手輸贏回溯套每筆付款。

三桶以大盲BB選擇：

桶BB範圍
低0 < BB ≤ 10
中10 < BB ≤ 500
高BB > 500

原合法BB都留原桶，既有存量不搬動。兩池跨手、跨桌及換SB保存，CD跨桶。例如SB2/BB4低桶、SB20/BB40中桶、SB2000/BB4000高桶。

JP需root win、啟用、特殊池足額；依皇家200BB／同花順50BB／四條20BB選最高可負擔獎，再抽預設20%資格。未足額不抽資格票。SB10、BB20時皇家4000、同花順1000、四條400。

有資格布局須玩家底牌參與，公牌不能自行構成特殊牌，牌型須精確吻合。只有玩家獲勝攤牌且與資格相符才扣池派一次；棄牌不扣不派，資格不跨手。本手新入特殊池不能回頭資助開局資格，不是任何自然特殊牌都自動有JP。

10. 結算、退款與保存

Cp/Cn為雙方總投入，m=min(Cp,Cn)：

refund_i = Ci - m
matched POT = 2 × m
gross_i = 勝方 2m；平手 m；負方 0
netReturn_i = gross_i
totalReturn_i = netReturn_i + jackpotAward_i
profit_i = totalReturn_i - m
stackAfter_i = stackBefore_i - Ci + refund_i + totalReturn_i

fee=0。雙方桌碼總和只因實際JP增加；個人池另按before−使用／派出+收入對帳，不算錢包。TOTAL WIN使用totalReturn，不含退款。

每位收款者應得的netReturn以一整包POT收回，金額連續累加；平手各收一包應得額。玩家TOTAL WIN與籌碼由同一呈現進度上跑至最終值。退款及JP仍為獨立帳務／階段，顯示只讀已提交結果，不再加錢或重派獎。玩家桌碼歸零時完成整手表演後自動離桌，回SB／BUY-IN入口；重新按FIGHT才買入，不自動補碼。

profile儲存鍵沿用magic-poker-lite.player.v1，資料version2一次保存BALANCE、三桶雙池、CD、上一對手及table。table包含session、未完手、布局、結果路徑、籌碼、歷史、街道快照和RNG。買入、開手、正式動作、結算及離桌均保存。

重整或重開頁面先結束保存中的舊桌，再回買入入口。未完手按玩家離桌棄牌結算，即使可免費CHECK或正在等NPC；若玩家已全下等待NPC回應，則使用保存RNG依正常NPC分布抽回應並完成結算。沿用未匹配投入全額退款及池帳，結算後剩餘玩家CHIPS兌回BALANCE一次。已結算手不重派；買入動畫尚未開手時兌回全部玩家桌籌碼。

snapshot／restore底層保留供結束舊桌帳務使用，UI不接續舊手。以一次保存提交BALANCE、結算後雙池／CD、上一型及空table；保存失敗保留原存檔、顯示提示並阻止新買入，避免重複兌回或遺失桌籌碼。錢包、水池、CD和對手序列繼續保留，不重設初始資產。

舊version1餘額與池可遷移。設定匯入不改遊戲資產。此為本機單瀏覽器帳務，不涵蓋跨裝置或多分頁同步。

11. 公開參考與研究

德州參考勝率只使用玩家兩張底牌及已揭0/3/4/5公牌；不讀NPC暗牌、未揭board、水池或結果目標。對手牌型range在雙方底牌發完即顯示：Preflop排除玩家底牌後精確枚舉C(50,2)=1225組，顯示當前兩張未知牌的Pair／High Card分布，不補未來公牌、不預測河牌。Flop／Turn／River仍依未知底牌與已揭公牌計算當前最佳五張分布。這是標準未知牌參考，不是實際NPC底牌或結果控制模型的真實後驗勝率。

機率工具共用正式引擎與相同合法動作。一般研究外部錢包無限，每次入桌仍是100SB有限碼，桌碼按各手輸贏累積，歸零才模擬新入桌。NPC每手匹配玩家碼。tableEntries/tableBuyIns另列，買入不計入有效投入／返還。

退幣總資產=外部錢包+桌碼，水池排除；達標即成功，桌碼歸零且錢包不足新買入則失敗。不對未完手補碼，不設額外安全手數上限。每位玩家有自己的池、CD及RNG，研究重入保留其池與對手序列。

一般與退幣研究以共用beginNewTable重入：從同一RNG序列重新抽新桌首盲，之後依新桌手序交替；保留總手數、池、CD、累計結果及上一型。外部錢包轉帳由研究呼叫方處理，新桌尚未開手不能再次重入。新桌入場不等同於同桌補碼。

一個開始按鈕先跑一般再退幣，四種玩家策略保留。空白種子每次開始隨機一次，明確0有效；全策略和兩階段共用本次seed。全部指定退幣玩家及策略完成才發布比例；停止/失敗保留完成的一般結果，不發布部分退幣率。報表明示實際mode和seed。

12. RTP、報表與驗證邊界

baseRtp = Σ netReturn / Σ matchedWager
totalRtp = Σ totalReturn / Σ matchedWager
refundRate = 達標玩家數 / 全部指定玩家數

退款從投入與返還分母／分子排除；未派水池餘額不是返還。NPC起始配置和重新買入不是遊戲獲利。RTP與退幣率是不同指標；.99是計分設定，不能代替實測值。

跨手池造成相依，一般與退幣研究不把各手當完全獨立：CI按玩家聚類；樣本不足或零分母不可估。單手冷啟動樹或小樣本不能證明長期RTP。

歷史完整樹API如保留須標示其模式；pooled-holdem預建的是牌面候選，抽樣控制路徑不是全NL樹，不能用葉子比例當勝率。舊5BET門檻校準不再用於本版固定100SB買入。

發布前核對正式測試、錢包與池對帳、手機viewport和公開內容；先前fixed-holdem候選測試不算新mode驗證。桌面Chrome手機尺寸也不等於實體Android。實際結果見 驗證與發布。
