Magic Poker Lite

現行 v51 規則：Hands Up RTP 計分、個人雙水池與底池全額派彩 · 2026-10-06

本文件描述現行 v51 模型；使用者已授權提交並推送 main，由既有 GitHub Actions 建置與部署 Pages，實際結果以 Actions 為準。驗證範圍見 驗證紀錄。遊戲英文，工具與文件繁體中文；原三款永久唯讀。

這是一款按結果目標預建牌面的德州風格原型：雙方仍依真實最佳五張、合法下注與 POT 結算，但牌面不是均勻隨機標準德州。玩家可見牌的參考勝率與內部結果目標是不同資料，不能互相冒充。

2. 入桌、開局門檻與個人資料

遊戲入口預選 BET 1。入口及局間 BET 固定級距為 1、2、5、10、20、50、100、200、500、800、1,000、1,200、1,500、1,800、2,000。兩盲、四街下注額及門檻依 BET 比例縮放。

最低資產以公開設定計算：

minimumAssetsForBet = round6(config.minBuyIn / config.bigBlind × BET)
門檻倍數 = ceil(新模型平均每手 player.totalContribution / BET)

平均原始實扣包含後來退回的下注，不是 matchedWager 或淨損益。它是預先校準的固定門檻，不依這一手秘密牌面、個人近期輸贏或水池餘額浮動，也不保證所有加注路徑都付得起。

首次 FIGHT、同 BET 的 NEXT HAND、改 BET 都檢查雙方真實資產。低於門檻時拒絕開手，先於本次正式手數、RNG 推進、盲注扣款與布局發布。不足時 NEXT HAND 開 BET 視窗，玩家手動選較低級距或離桌；取消保留原值，不自動降低、不補資。最低 BET 仍不足時不能開新手。已開始的牌局可正常全下、退款及結算。

個人資料鍵 magic-poker-lite.player.v1 保存 {version:1,balance,outcomePools}。同一筆已結算交易同時保存餘額、兩種三桶水池、CD、資格序號與跨桌 handSequence；換桌、換 BET、重新載入都保留。未完成牌局時重整，恢復前一筆已結算整手快照，沒有後端續局或未完成牌局恢復。Reset demo chips 僅重設測試資產，保留水池。儲存不可用時不能假稱保存成功。

設定另存 magic-poker-lite.config.v2。舊設定的預設門檻遷移與個人資產／水池分開，不覆蓋已保存個人池。工具的初始池參數只設定研究玩家起點，不在每手重新歸零。

3. 開局完整結果樹與牌面

每次玩家入場並開始新一手後，才依當時狀態建樹；先在隔離的 hand／session／RNG 上展開全部合法動作，包含機率為零的合法分支。root 先抽目標，每個玩家付費節點再依父節點目標與該分支水池決定是否抽轉贏；全部目標及水池分支狀態完成後，才嘗試未公開的牌面布局。

行為結果目標與水池規則
玩家免費 CALL（check）繼承父節點目標及水池，不抽結果、不扣 CD
玩家付費 CALL／RAISE（含 bet）且父目標 nonWin依付費分數與可用付費池抽能否轉 win
玩家付費且父目標 win保持 win、不抽結果、不用池、不扣 CD；仍記贏節點付費待入池
BOSS 非棄牌動作繼承玩家目標及水池，不額外給玩家轉贏抽籤
玩家 FOLD終局 BOSS 贏，覆蓋目標
BOSS FOLD終局玩家贏，覆蓋目標

win 表示後續不棄牌時的玩家攤牌勝利；nonWin 容許輸或平手。下一手重新抽 root，不把本手 win 延到下一手。

每次候選布局固定玩家兩張底牌與完整五張公牌序。引擎在開局找出符合各目標的 BOSS 暗牌組，保存至各節點；免費動作不更換目標，付費由 nonWin 轉 win 才切到已預建的對應暗牌分支。已公開的玩家牌、公牌及揭牌順序不能因下注改變。每條分支都是不重複的合法 52 張牌狀態；不同反事實分支可使用彼此重疊的 BOSS 候選牌。

玩家起手候選預設未成對時有 50% 重抽，最多 50 次，接受最後候選，再依目標與特殊資格建立完整布局。BOSS 暗牌按節點目標選取。指定研究牌保持原牌；指定 BOSS 無法滿足完整樹的全部目標時原子失敗。

布局不符合任一目標或特殊資格時，重建整棵未公開布局，所有已抽目標及特殊資格不重抽。超過節點／布局上限報錯，不發布截斷樹、不扣正式盲注、不推進正式 session。成功才原子提交。

正式玩家操作只讀已存 edge／node，不臨時找牌或抽 target。BOSS 的實際行動仍依當下合法固定分布抽取一次，以選擇已存在的分支；動畫不能再抽一次。分析遍歷與按鈕 preview 使用隔離資料，不推進正式 RNG 或水池。

畫面的標準德州參考機率只讀玩家已知兩張牌及已揭公牌。它忽略內部目標、水池、重抽與配牌限制；不能當作實際遊戲勝率、付費轉贏率或 BOSS 行動率。

  • 玩家 equity：補完未知公牌後以 (wins + ties/2) / outcomes 計算。PREFLOP 為獨立固定 100,000 次抽樣；FLOP／TURN／RIVER 分別完整枚舉 1,070,190／45,540／990 個等權組合。

  • 隔離 Worker 僅收公開玩家牌與公牌，不傳手牌樹、目標、BOSS 暗牌、池餘額、seed 或未揭牌序。

5. 個人雙水池與特殊 JP

兩種池初始都為零，工具可明確設定研究起點。池是個人持續保存的結果預算，不是可直接兌現的錢包餘額。三桶如下，CD 則跨三桶共用：

桶BET 級距
11、2、5、10
220、50、100、200、500
3800、1,000、1,200、1,500、1,800、2,000

5.1 Root 目標

令 α=0.99，m0 是兩方盲注已匹配金額：

rootScore       = round6(m0 × α)
rootDenominator = round6(2 × m0)
rootProbability = clamp(rootScore / rootDenominator, 0, 1)

完整正常盲注下預設 root win 機率為 0.495。root 不扣付費池，也不增加任一池；只有 root win 才檢查特殊資格。

5.2 付費 nonWin 轉 win

c 為本次實付，C 為玩家操作前本手累計投入，S 為 BOSS 本手起始資產；B 為此桶當前付費池：

M = min(C + c, S)
D = round6(2 × M)
s = round6(c × α)
U = CD==0 ? min(B, round6(max(0, D-s))) : 0
p = clamp(round6(s+U) / D, 0, 1)

D 使用此動作補齊匹配後的全額 POT，不是 BOSS 尚未跟注的瞬時 POT；不含退款或 JP。U 不能超過池餘額或把機率補過 100%。實際選到該付費節點才提交已預建的 U 消耗，無論此次抽中 win 或仍為 nonWin 都扣 U；未走分支不扣任何池。

CD>0 時不使用池，若前節點 nonWin 且實際執行付費動作，CD 扣 1。使用 U>0 時依設定的包含端點整數範圍指定新 CD；min=max 時無額外 CD 亂數。前節點 win 時不重抽、不使用池、不遞減 CD。

抽票尺度為 1,000,000：winningNumbers=round(p×1000000)，抽 roll=1+floor(rng×1000000)；roll<=winningNumbers 才中。0%／100% 的結果抽籤仍各使用一次結果票；win 繼承不抽結果票。

5.3 贏節點付費的 80%／20% 入池與退款

本次付費節點 target 為 win 時，保存其玩家投入區間 [C,C+c]。手內不立刻把這筆收入入池；結算以最終每方有效投入 m 剪裁：

effectivePaid = max(0, min(C+c,m)-C)
creditScore   = round6(effectivePaid × α)
paidPoolAdd   = round6(creditScore × 0.8)
specialAdd    = creditScore - paidPoolAdd

各筆有效區間分別計算後加總，盲注不入池，未匹配退款不入池。這裡的「贏節點」是付費當時的內部 target；後續玩家自行棄牌仍以該已執行節點及最終匹配區間核算，不能改用整手 winner 回頭重抽或重寫 target。由於 win 後本手不再消耗付費池，延後收入不改變本手後續轉贏決策。

5.4 特殊池資格與派彩

root win 時，從此 BET 桶的特殊池挑最高可負擔一項：皇家同花順 200×BET、同花順 50×BET、四條 20×BET。足額才抽 20% 出現率；不足連四條也付不起時不抽資格票。

命中後鎖定本手資格及對應特殊牌布局，重建布局不能重新抽資格或降級。玩家底牌須參與：四條需底牌含四條點數；同花順／皇家需底牌參與該五張同花順。公共牌本身已形成任何特殊牌型的布局不接受。無資格的一般布局排除玩家特殊牌。

本作沒有換牌／魔法，因此資格沿本手所有正常下注分支保留。只有正常 showdown、玩家贏且實際牌型與資格精確一致時，才從特殊池扣指定獎額並單獨派 JP。棄牌不扣、不派；池資金留到後手，但這次已抽資格不持續保存到下一手。當手待入特殊池的收入不能回頭資助開局時不足的資格。

只派該資格的一獎，BOSS 不領；未取得資格不另派自然 JP。

6. POT、退款、池與可核對例子

令原始投入為 Cp、Cn，m=min(Cp,Cn)，匹配底池 G=2m：

refund_i      = C_i - m
gross_i       = 勝方 G；平手每方 G/2；負方 0
netReturn_i   = gross_i
fee_i         = 0
totalReturn_i = netReturn_i + jackpotAward_i
profit_i      = totalReturn_i - m
stackAfter_i  = stackBefore_i - C_i + refund_i + totalReturn_i

單手錢包守恆為：雙方結束餘額＝雙方起始餘額＋本手實際特殊獎額。水池是結果預算帳，不直接作錢包收入；入池時不能額外增加玩家資產。池另對帳：付費池期末＝期初－已用 U＋有效贏節點分數的 80%；特殊池期末＝期初－已派特殊獎額＋其餘 20%。

例一，BET 1、玩家已投入 0.5，本次 CALL 0.5，BOSS 可匹配足額，D=2、s=0.495。付費池為 2 且 CD=0 時，最多用 U=1.505，機率達 100%，池暫餘 0.495。最終匹配 1，這筆 0.5 全部有效，結算再入付費池 0.396、特殊池 0.099，付費池期末 0.891。

例二，已投入 1 的 win 節點再 RAISE 5，最終因 BOSS 棄牌只匹配到 2。該付費區間 [1,6] 只有 1 有效，4 退款；只入付費池 0.792、特殊池 0.198。若最終只匹配到 1，整筆加注退款，兩池收入都是 0。

例三，BET 1 的特殊池為 220、root win 且命中皇家資格。正常獲勝攤牌派 200，特殊池先扣至 20，再加本手有效付費的 20% 分數；若任何一方棄牌，JP 為 0，這份 220 不因資格而扣除。

7. 每手行動樹與離線校準

buildActionTree 先透過共用正式引擎建立本手完整結果樹，再遍歷已存合法分支；玩家／公牌布局固定，BOSS 暗牌依預建目標節點決定。它不在分析時重新抽目標或配牌。一般足額下注樹可能有 1,312 節點、750 終端；短資產及注額設定會改變形狀，不能硬認每手都相同。

每條 edge 的到達機率乘上父節點到達機率；每節點 expected 是「到達後，再依所選策略繼續」的條件期望。終端質量總和應為 1，不能以贏葉數／總葉數當勝率。玩家入場後，每次開始新一手才依當時資產、盲位、BOSS 與水池建立本手行動樹。工具的一般／退幣統計也逐手呼叫同一引擎，沒有獨立建樹入口或跨手共用樹。內部離線校準可檢查完整樹；暗牌、未來公牌、目標與水池路徑不送進遊戲公開 DOM。

simulateTreeStudy 每副從設定的初始三桶重新開始，對一個已建布局積分全部行動後再跨樣本平均。它是冷啟動單手研究，不是長期池狀態、不是所有牌面枚舉，也不是水池穩態 RTP。CI 樣本單位是一副樹，不是一片葉子。

8. 玩家研究與統計分母

一般研究固定連續遊玩、無限研究資產，每人完成指定手數；玩家行為只選策略。雙池、CD、BOSS 序列與隨機盲位跨手繼承，不設一般達標資產或額外安全上限。引擎每手用足夠涵蓋全部合法下注的有限額度，不能把 Infinity 放入帳務；此額度不是玩家錢包，報表起始／結束資產顯示無限。

退幣研究另用專用玩家數、初始資產、目標資產；固定 BET 持續遊玩到達標或不足每手門檻，沒有手數上限。退幣率＝達標人數／全部要求玩家數；全部玩家及策略完成後才發布比例。

底池 RTP＝總底池返還／總有效匹配投入；總 RTP＝（底池返還＋實際特殊獎勵）／有效匹配投入；淨利＝實際總返還－有效匹配投入。未跟注退款不進 RTP 分子或分母，未派池餘額不算返還。設定 99% 是抽籤分數係數，與實測比率分列。

水池跨手相關，因此一般研究按玩家整段投入／返還估算聚類信賴區間；樹研究按每副完整樹估算。少於兩個獨立單位或零分母時顯示不可估。罕見特殊獎的有限樣本不是長期 RTP 保證。

9. 機率工作台與保存

採 Hands Up 的單欄工作台、彩色連號折疊區塊與群組橫列表單；桌面兩欄、手機單欄。模擬設定、RTP 與水池、基礎遊戲規則、對手與玩家策略、指定研究牌依序排列。退幣位於模擬設定的玩家行為下方。只有一個全系統 RTP 設定。

固定種子空白時，每次開始產生一次隨機 uint32，所有策略、一般與退幣共用；結果保存實際種子。固定 0 有效。參數匯出空白為 null。

開始統計先跑所有一般策略，再跑所有退幣策略；兩者完成主按鈕才結束。停止或失敗保留完成的一般策略，取消本輪退幣比例。策略比較、切片、勝率分母、動作、個人資料及三桶雙池對帳均保存實際結果；分頁只顯示選中內容。

遊戲／工具載入或匯入設定時轉為現行模型，移除額外底池費，不覆蓋玩家 profile。參數 JSON v6、總結果 v9、專用退幣結果 v1；設定與報表可複製、匯入匯出。

10. 主要 API 與呈現

createSession(config,seed,{firstSmallBlind,outcomePools}) 接受個人池快照；startHand 原子建樹；applyAction 查已存分支；previewResponse 在 clone 上查當街直接回應；getActionDistribution 提供合法 BOSS 分布。完整資料契約見 API-CONTRACT.md。

firstSmallBlind:'random' 的首手沿用建立 session 時已抽盲位，後手成功開局再抽 50/50，允許連續相同盲位；研究可選 player／npc 受控交替。入口及局間 BOSS 預覽只用 RNG clone，不扣款、不發牌、不推進正式狀態。

遊戲動作槽固定 FOLD／CALL／RAISE；玩家付費按鈕顯示本次追加實付。金色 TOTAL WIN 顯示 netReturn＋JP、排除退款；BOSS WINS 不顯示 0 或其他分數。座位 SB／BB 不再附 YOU，抽盲 STARTING BET 仍列雙方真實盲注。公開揭牌才更新牌型、參考勝率、金框／藍框與音效，不得用內部目標偷跑演出。

11. 與 Hands Up 的適配界線

沿用 Hands Up 的單一 99% 計分、開局抽目標、付費轉贏、win 繼承、80%／20% 個人池、三 BET 桶、全局 CD、最高可負擔特殊牌與 20% 出現率，並在開局完整建樹。

本作保留雙方形成的 POT，沒有 Hands Up 的固定本關 Cash out、換牌或魔法。轉贏分母改為本次下注可匹配後全額 POT；原作不可退款的付費，改成在結算時依有效匹配投入分池；特殊資格原作限 N0 直接比牌，本作則沿不換牌的正常下注分支保留至玩家獲勝攤牌。水池運行相同；德州下注的可退款投入以最終匹配區間核算。

BOSS 列平均固定表是本作行為規格，標準德州參考勝率仍是公開資料輔助。原三款只讀，本作程式不依賴原目錄。
