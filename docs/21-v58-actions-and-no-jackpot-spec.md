## 1. 取消 Jackpot

正式 `pooled-holdem` 不再提供 JP 入口、說明、資格抽取、額外派獎或研究設定。舊設定不能把正式 JP 重新開啟。自然四條、同花順、皇家同花順仍按一般牌力參與勝負，不因沒有 JP 資格被額外排除。

贏節點有效付費的 .99 計分全部進一般付費池，不再按 80%／20% 分流。舊特殊池餘額併入同一 BB 桶的一般付費池，特殊池歸零；保留總池存量與 CD，不轉成錢包或實際返還。遷移重做不再增加存量。三桶 BB 邊界保持不變。

舊未完桌先按原保存契約結束並兌回一次，再遷移池供新桌使用；既有已派 JP 不追回、不重派。明確指定的歷史研究 API 可保留舊契約及相容欄位，不能成為正式工具選項。

## 2. 玩家 2× POT、4× POT、ALL IN

玩家 BET／RAISE 三個尺寸改為 2× POT、4× POT、ALL IN，選單由上到下維持大額在上：ALL IN、4× POT、2× POT。

P 是提交行動之前的當前 POT，s 是玩家本街已付：

```text
2× POT：本次支付 = 2 × P
4× POT：本次支付 = 4 × P
本街累計 to = s + 本次支付
最低合法 to = currentBet + lastFullRaise
最終 to = min(s + 剩餘碼, max(最低合法 to, 報價 to))
ALL IN：本次支付 = 剩餘碼
```

例如 P=100，2× 本次支付 200、4× 本次支付 400，不再另外加 CALL。最低合法加注及剩餘碼封頂仍適用，合法同額選項合併。短全下不重新開放已行動者加注權。UI 顯示實際支付金額並傳完整動作 ID，不能只傳 raise。

NPC 自己的下注尺寸仍為半池／全池／ALL IN，條件權重 50%／35%／15%；每街強弱分類及 v56 的實際壓力回應表保持。2× 與 4× 若都落大額壓力，可以有相同回應機率，不為了視覺差異更改機率。

## 3. 雙方行動字卡與語音

玩家及 BOSS 每次正式提交行動後顯示 YOU／BOSS 與 CHECK、CALL、BET、RAISE、ALL IN 或 FOLD 英文字卡，同時播放相應英語語音。實際支付到全下時顯示 ALL IN，包括短 CALL 全下；FOLD 是棄牌的正確英文。

以已提交 history 事件識別演出，同一次行動只演出一次。預覽、重繪、載入舊桌結算不重播。語音沿用 Sound effects 開關，關閉聲音仍顯示字卡；遵守使用者手勢解鎖、背景／離頁取消，不讓語音佇列在返回後重播。音檔隨網站發布，不依賴外部 API。字卡不遮玩家牌、公牌及操作選單。

## 4. 首次入桌抽盲，BOSS 隨機

每次新入桌只在第一手播放一次 50／50 小盲／大盲抽取，後續手直接交替盲位、顯示座位標記及下盲，不再播放抽取。重新買入是新桌，可重新抽一次。

每手獨立以 50／50 選 AGGRESSIVE 或 PASSIVE，允許連續相同類型；不再排除上一型。研究仍可明確固定一型。抽 BOSS 不新增選人輪盤；入場只演出盲位抽取。對手起始籌碼仍匹配玩家。
