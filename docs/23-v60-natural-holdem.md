# Magic Poker Lite v60 規則與數學

更新：2026-10-08。使用者授權將討論架構實作、驗證、更新 Git，再開新聊天室提供連結。正式模式改為 natural-holdem，採一次均勻洗牌作為明確出牌基準。**本版沒有固定99% RTP保證。** 非均勻布局抽取、退出報價、額外派彩及跨手追補未採用。實際驗證與部署以 [發布紀錄](06-mobile-and-deployment.md) 為準。

## 2. 入桌與開手

選 SMALL BLIND，BIG BLIND為兩倍，BUY IN為100倍小盲。FIGHT只把錢包轉到桌碼一次。桌碼跨手延續，同桌不補碼；每手BOSS帶入額匹配玩家當時桌碼。首次入桌50/50抽盲位，其後每手交替。兩型BOSS每手獨立各50%，允許連續相同。

開手先選BOSS，再對52張牌進行一次Fisher-Yates洗牌，由小盲、大盲交替取得兩張底牌，餘牌前五張固定為Flop／Turn／River。沒有起手重抽、指定牌、先抽贏家或找牌重試。下注和BOSS決策不能更換任何底牌或未揭牌序。

開手及操作先在隔離副本完成，通過合法性與完整性檢查才提交資產、手號和RNG。牌序、底牌、規則及開手設定凍結；JSON還原後驗證再凍結，不生成替代牌局。未知規則、牌張或設定與快照不符時拒絕，不提交部分付款。

## 3. 完整行動流程

Preflop小盲先，之後大盲先。小盲第一次補平後，大盲保留CHECK／RAISE權。兩次CHECK或一般CALL結束本街；River結束攤牌。玩家進攻後，BOSS可依法FOLD／CALL／再RAISE，然後再次輪到玩家；不限成只有一輪回應。完整加注重開權利，短全下不重開已行動者加注權。

| 狀態或動作 | 後端處理 |
| --- | --- |
| 無欠注 | CHECK及合法BET／RAISE |
| 有欠注 | FOLD／CALL及合法RAISE |
| 無加注權或對手全下 | FOLD／CALL，短碼為CALL ALL IN |
| 玩家2×／4× POT | 本次實付為當前POT的2／4倍，不另加CALL |
| BOSS半池／全池 | 本次實付為C + 0.5(P+C)／C + (P+C) |
| ALL IN | 支付剩碼，是BET／RAISE／CALL的付款狀態 |
| FOLD | 立即結束本手，沒有退出補償報價 |

C是行動者欠注，P是行動前POT。報價先滿足最小合法加注，再以自己的剩码封頂，同額合併。未被對方匹配的額度可能退款，不能先當成有效投入。付款只改投注狀態，不再抽「是否轉贏」。極短盲可直接runout，或留下最後一次FOLD／CALL應答。

## 4. BOSS資訊與行動機率

引擎只提供BOSS自己的兩張牌、當前已揭公牌、雙方籌碼、底池、可付CALL、壓力基準底池、白名單行動歷史及合法動作。專用decision view深度凍結；策略不接收完整hand、玩家暗牌、未揭牌、牌序、RNG、結果目標、池或返還缺口。

PASSIVE較常跟注／過牌，AGGRESSIVE較常進攻。新版依成牌、涉及底牌的聽牌、過去進攻、阻擋牌與實際下注壓力連續計算權重，不沿用舊三檔固定表。強牌較能承受價格壓力；只由自己的牌及已揭公牌即可證明River不可能輸時不FOLD，共同不敗公牌只CHECK／CALL。完整公式和參數見 [BOSS策略](../src/boss-policy.mjs)。這是體驗用啟發策略，牌力分數不是精確勝率，也不是RTP校準公式。

機率只在合法動作上正規化。免費時無FOLD，無加注權時無進攻；合併尺寸合併權重。正式先抽行為，BET／RAISE再抽尺寸；兩型各有自己的尺寸權重，ALL IN權重另依牌力調整，不沿用舊50／35／15固定比例。

預覽與正式回應使用同一策略，預覽只操作隔離副本，不改正式牌、資產或RNG。實付額度、歷史與狀態相同即相同機率；不同壓力通常不同，短碼合併尺寸仍可相同。文字才四捨五入，整高色塊使用完整比值。公開精確機率仍可能透露牌力資訊，不能稱為完全無資訊。

## 5. 結算、退款與資產

玩家FOLD由BOSS贏；BOSS FOLD由玩家贏。全下應答完成後，公牌按固定3／1／1順序發完；River結束比較七張中最佳五張，平手平分。

| 項目 | 計算 |
| --- | --- |
| 玩家／BOSS累計投入 | U／V |
| 有效匹配額 | M = min(U,V) |
| 玩家／BOSS未匹配退款 | U − M／V − M |
| 匹配底池 | 2M |
| 玩家實際派彩 | 贏2M／平手M／輸0 |

沒有抽成、JP或退出報價；退款另記，不算額外派彩。每手只結算一次。TOTAL BALANCE為桌外錢包加呈現桌碼，profile.balance只存錢包；買入／離桌兌回不重複記為投注或獎金。

舊個人池存量保留為歷史相容資料，新牌局不新增、不消耗、不兌成資產。未派池不是玩家已收到的返還。設定匯入只影響新桌，不覆寫錢包；舊指定牌與結果控制設定不進入新桌。

## 6. 舊桌、重整與保存

v57／v59未完桌按保存的模式、牌局、結果池分支及RNG結束，再開新自然桌。未全下時離桌FOLD；已全下者正常完成BOSS回應及攤牌。已派款不追回、不重派，餘碼只兌回一次。

新自然桌重整同樣先結束保存的那一手，不重發替代牌局。保存失敗或牌序／規則驗證失敗時保留原存檔，阻止新買入。v59相容fixture由已發布提交363aa41999ad6762bfdc98fea8c7588b83b52843的實際程式產生，涵蓋未完手、全下棄牌、全下攤牌與已結算。

## 7. 勝率、RTP與研究口徑

玩家參考勝率只用自己的牌和已揭公牌，依未知牌分布估計攤牌勝率；它不包含BOSS未來行動，也不是本手獲利或RTP保證。BOSS牌型分布入口維持移除。

實測RTP = 玩家實際派彩總和 ÷ 玩家有效匹配投入總和。BOSS投注不進分母；買入、離桌兌回、未匹配退款與未派池不當額外派彩。工具記錄seed、實際完成手數、策略、重入次數、規則及BOSS版本。一般研究可從外部研究錢包重新入桌，但每桌有限100SB、桌碼跨手延續；不能把重入當同桌補碼。

本版不使用 .99 結果計分，也不保證所有策略99%。普通FOLD、停玩與自適應策略都會影響返還。有限樣本、玩家聚類信賴區間、池帳／錢包守恆或測試通過，不等於全部策略長期RTP認證。非均勻牌局、額外結算和全策略RTP求解沒有宣稱完成。
