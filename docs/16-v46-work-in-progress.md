## 已整合的規格

- 正式預設 prebuilt-pools。開局先完成 root／全部付費節點目標及分支池狀態，再建立實際牌面；玩家底牌與公牌序固定，BOSS 暗牌由預存節點選取。玩家操作只讀分支，不臨時抽目標或找牌。無解保留target／特殊資格重建未公開布局，超限原子失敗。
- 所有玩家付費 CALL／RAISE（含bet）在父目標nonWin時有機會轉win；免費與BOSS非棄牌繼承；win吸收但付費仍記入池分數；fold覆蓋終局。nonWin容許平手。
- 0.99為轉贏計分係數，0.96為POT返還係數；保留雙方真實下注形成的POT與未跟注退款，不把任何一個係數稱為整體RTP。
- 完整個人付費池＋特殊池，三個固定BET桶，CD跨桶共用且預設0..0。贏節點付費按最終matchedWager剪裁後80%／20%分池，原始盲注與退款不入池。只有實際選中路徑提交。
- root win、特殊池足額時選最高可負擔200／50／20倍BET牌型，再抽20%資格。無資格普通布局排除玩家特殊牌；玩家底牌須參與，有資格且玩家正常攤牌獲勝、tier一致才扣池派JP。棄牌保留資金，不保留這次資格到後手。
- BOSS正式使用four-boss-fixed-street-v2，每街原牌力列等權平均，決策不讀私牌牌力；依合法動作剔除後正規化。首手均等與排除上一型輪替保持。
- magic-poker-lite.player.v1一筆保存已結算balance＋pool/CD/序號，換桌／換BET／reload保留。未完手reload回上筆已結算交易；Reset demo chips只重設資產，保留池。這是本機demo保存，未接後端續局。
- 資產門檻套用每手FIGHT／NEXT HAND及同BET／改BET，失敗不扣款或推進正式RNG。不足開BET視窗讓玩家自行降低或離桌，不偷偷降BET或補資；局中仍可全下。
- 保留BOSS WINS金色無框無數字、座位SB／BB移除YOU、TOTAL WIN與公開揭牌／音訊契約。遊戲英文，工具與文件繁中，原三款永久唯讀。

本機引擎、獨立樹核心、布局產生器、雙池、個人profile及研究工具已完成整合；正式預設使用同一套結果樹與雙池模型。驗證證據及限制見下方與[docs/06](06-mobile-and-deployment.md)。
